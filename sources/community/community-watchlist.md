# Community and Secondary Sources Watchlist

This file lists community, newsletter, and media sources that can be used for discovery and secondary context. These sources should not replace official documents, GitHub repositories, regulatory texts, filings, or company announcements.

## Principle

Community sources are useful for discovering signals, not for final verification.

Use them to identify:

- New GitHub projects
- Developer sentiment
- Emerging use cases
- Product complaints or adoption signals
- Early discussions around agent frameworks, MCP, tools, and coding agents

Then verify important claims through official sources, GitHub, filings, or reputable financial/regulatory sources.

## Developer Communities

- Hacker News
- Reddit r/OpenAI
- Reddit r/ClaudeAI
- Reddit r/LocalLLaMA
- Reddit r/MachineLearning when relevant
- GitHub Discussions and Issues from tracked repositories

## Newsletters and Industry Commentary

- Latent Space
- The Batch by DeepLearning.AI
- Ben's Bites
- Import AI
- The Information where accessible
- SemiAnalysis where relevant to chips, compute, and data centers

## Financial and Business Media

Use these primarily for secondary market context, M&A, financing, and strategic interpretation:

- Reuters
- Bloomberg
- Financial Times
- Wall Street Journal
- CNBC
- Barron's
- MarketWatch

## Usage Rules

1. Do not treat community discussion as confirmed fact.
2. Use community sources to find topics worth checking.
3. Important claims must be verified with official sources, GitHub repositories, regulatory filings, or reputable media.
4. Clearly label uncertain or media-reported information.
5. Avoid low-value listicles, generic tool rankings, and SEO content farms.
