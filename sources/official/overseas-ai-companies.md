# Overseas AI Company Official Sources

This file defines the preferred official sources for tracking overseas AI company product and technical updates. Use these sources before community posts or media summaries.

## Source Priority

- P0: Official company websites, developer documentation, release notes, official blogs, official GitHub repositories, API documentation.
- P1: Company investor relations, official product changelogs, engineering blogs, security/safety pages.
- P2: High-quality financial or technology media, used only as secondary context.
- P3: Social media, newsletters, and community discussion, used only as discovery signals.

## Reporting Rules

When using company sources:

1. Prefer official product documentation or release notes over media summaries.
2. Separate product updates from technical architecture implications.
3. Distinguish confirmed capabilities from roadmap language.
4. Include source links for important claims.
5. Avoid generic model benchmark updates unless they affect agents, tools, enterprise adoption, developer workflows, or product architecture.
