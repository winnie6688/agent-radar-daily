# GitHub Sources: Agent Frameworks and Developer Ecosystem

This file tracks GitHub repositories relevant to AI agents, coding agents, MCP, skills, workflow automation, and agent infrastructure.

## Source Priority

- P0: Official repositories from OpenAI, Anthropic, Google, Microsoft, GitHub, and major protocol organizations.
- P1: Highly active open-source repositories with frequent releases, clear documentation, and meaningful adoption.
- P2: New or fast-growing projects that are relevant to AI agents but require validation.
- P3: Experimental repositories used only as signals.

## What to Track

For each relevant GitHub project, evaluate:

1. Recent release activity.
2. Star growth or sudden community attention.
3. README clarity and examples.
4. Whether it supports MCP, tools, skills, workflows, or agent orchestration.
5. Whether it is suitable for product architecture learning or practical prototyping.
6. Whether it is maintained by a credible team or organization.

## Reporting Rules

When reporting GitHub projects:

- Separate official repositories from community projects.
- Do not overstate maturity based only on GitHub stars.
- Highlight what the project actually enables.
- Include why it matters for AI agent architecture.
- Mention whether the project is experimental, developer-focused, enterprise-ready, or suitable for learning.
